This experiment focuses on implementing JavaScript styles and animations through an interactive Photography Portfolio website named LUMIÈRE – Photography & Visual Stories. The webpage demonstrates various JavaScript concepts, including timing events, Date Objects, DOM manipulation, mouse events, arrays and objects.

The experiment consists of five programs: displaying a digital clock using the Date Object and setInterval(), dynamically changing background colours using random RGB values, increasing and decreasing font sizes using mouse events, creating camera movement animations using setTimeout() and clearTimeout(), and displaying student details using arrays of objects and conditional statements.

HTML and CSS are used to design a professional photography portfolio interface, while JavaScript provides interactive functionality and animations. This experiment helps understand how JavaScript can dynamically modify webpage styles, handle events and create engaging user experiences.
